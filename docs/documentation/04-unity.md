# Unity 작업 기본 규칙

컴포넌트 코드를 작성하거나 씬·프리팹을 수정할 때 보는 공통 규칙입니다.

| 작업 | 지킬 규칙 |
| --- | --- |
| 초기화 | 자신의 컴포넌트 참조는 Awake에서 준비하고, 다른 객체 연결은 초기화 완료 시점을 확인한다. |
| 이벤트 구독 | OnEnable에서 구독했다면 OnDisable에서 해제한다. |
| 상속 함수 수정 | 부모가 하는 일을 확인하고 필요한 base 호출을 유지한다. |
| 에셋 이동·필드 이름 변경 | .meta와 GUID를 보존하고 씬·프리팹 참조를 확인한다. |
| 에디터 기능 작성 | Editor 폴더 또는 UNITY_EDITOR 조건으로 런타임 코드와 분리한다. |
| 풀 객체 재사용 | 이전 상태와 구독을 정리한다. 이 프로젝트의 ObjectPool.Get은 자동 활성화하지 않는다. |

수정한 기능은 Play Mode에서 실행·재활성화하고 콘솔 오류를 확인합니다. 이 페이지는 작성 규칙이며 실행 검증 결과가 아닙니다.
